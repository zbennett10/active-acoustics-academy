# From hydrophones to beams

## Why arrays

A single hydrophone hears everything from everywhere. It cannot say where a sound came from, and it gives the echo no advantage over noise arriving from other directions.

An **array** is a set of hydrophones at known positions, combined so that sound from one chosen direction adds up and sound from elsewhere does not. That buys two things at once:

- **Direction.** The array reports which way the echo came from.
- **Gain.** Noise spread over all directions is mostly rejected, so the echo stands higher above it.

Everything about an array follows from its size measured in wavelengths. A longer array, or a higher frequency, means a narrower beam and more gain.

$$
\lambda = \frac{c}{f}
$$

At 3.5 kHz the wavelength is 0.43 m. At 300 Hz it is 5 m, which is why low-frequency arrays are towed on long cables.

:::key
The array’s job in the sonar equation is to lower the noise term. An array with 20 dB of gain makes the noise at its output 20 dB lower than a single hydrophone would hear.
:::

## Delay and sum

The basic beamformer is simple enough to hold in your head.

A plane wave from some direction reaches the hydrophones one after another. The far end of the array hears it later than the near end, by an amount set by the geometry. **Delay** each hydrophone’s signal by just enough to cancel that difference, then **sum** them.

- For a wave from the chosen direction, the delayed signals line up and add: $N$ hydrophones give $N$ times the amplitude.
- For a wave from another direction, the delays are wrong, the signals are out of step, and the sum is small.

::play

Repeat with a different set of delays and the same hydrophones form a beam in a different direction. A modern sonar forms all its beams at once from one set of recordings. Nothing physically turns.

:::try
Set the test arrival equal to the steer angle: output is 0 dB, full strength. Move it a few degrees off and the output falls into the first null. Keep going and you ride up and down the sidelobes.
:::

## Steering

The delays that point a line array at an angle $\theta_0$ from broadside are, for a hydrophone at distance $x$ along the array:

$$
\tau(x) = \frac{x \sin\theta_0}{c}
$$

Two directions have special names. **Broadside** is perpendicular to the array, with no delays at all. **Endfire** is along the array, with the largest delays.

Steering away from broadside has a cost. The array looks shorter when viewed at an angle, so the beam widens, roughly as $1/\cos\theta_0$. A beam of 6° at broadside is about 12° at 60°.

A line array also cannot tell the two sides apart, or up from down. Every direction that makes the same angle with the array line gives the same delays, so the beam is really a **cone** around the array axis. For a horizontal towed array this is the left-right ambiguity. Resolving it takes a turn, a second line, or elements that are themselves directional.

:::pipeline
A beam is defined in the array’s own frame. To place it in the world you need the array’s heading and, for a towed or tilted array, its attitude. For a cone-shaped beam there is no single bearing at all, only a curve on the map.
:::

# Pattern numbers

## Beamwidth

The **beamwidth** is the angular width of the main lobe, conventionally between the points where response has fallen by 3 dB, half power.

For a line array of length $L$, unshaded and steered broadside:

$$
\text{beamwidth} \approx 51° \times \frac{\lambda}{L}
$$

| Array length | At 3.5 kHz, λ = 0.43 m | At 500 Hz, λ = 3 m |
|---|---|---|
| 2 m | 11° | 76° |
| 10 m | 2.2° | 15° |
| 100 m | 0.2° | 1.5° |

Beamwidth sets three things in a prediction:

- **Bearing accuracy.** A contact is somewhere inside the beam.
- **Reverberation.** The scattering area contributing at any instant is as wide as the beam. Halve the beam and bottom reverberation drops 3 dB.
- **Resolution.** Two targets inside one beam at the same range are one contact.

:::operator
Beamwidth in degrees becomes width in meters at range. A 10° beam is 1.7 km wide at 10 km. That is the cross-range size of the cell the sonar is listening to.
:::

## Directivity index and array gain

**Directivity index**, DI, measures how much an array reduces noise that arrives equally from all directions, compared with a single omnidirectional hydrophone.

For a line of $N$ hydrophones spaced half a wavelength apart:

$$
DI = 10 \log_{10} N
$$

More generally it depends on aperture in wavelengths:

| Array | Directivity index |
|---|---|
| Line of length $L$ | $10 \log (2L/\lambda)$ |
| Flat panel of area $A$ | $10 \log (4\pi A/\lambda^2)$ |

DI is an ideal. It assumes the noise really is the same in every direction and the signal is perfectly aligned across the array. What an array actually achieves is its **array gain**, AG, and the two differ whenever:

- noise is directional, which it usually is
- the signal is not perfectly coherent across the array, because of multipath or a rough path
- hydrophones have failed

:::key
DI is a property of the array. Array gain is a property of the array **in a particular noise field**. A model that knows only the array uses DI. A measurement taken at the beam output already contains the true array gain.
:::

## Sidelobes and shading

A beam does not respond only in its main lobe. It has **sidelobes**: weaker responses in other directions. For a uniformly weighted line array the first sidelobe is only 13 dB below the main lobe.

Thirteen decibels is not much protection. A loud ship 30 dB above the background, sitting in a sidelobe, still appears 17 dB above background on a beam that is not pointed at it.

**Shading** lowers the sidelobes by weighting the hydrophones unequally, strongest in the middle and tapering toward the ends. The price is a wider main lobe and slightly less gain.

| Weighting | First sidelobe | Main lobe width |
|---|---|---|
| Uniform | −13 dB | 1.0 × |
| Hamming | about −40 dB | 1.5 × |
| Hann | about −31 dB | 1.6 × |

:::try
In the beamformer bench, switch between uniform and Hamming weighting and watch the two numbers trade. Then place the test arrival on a uniform sidelobe peak and change the weighting.
:::

## Spacing and grating lobes

Hydrophone spacing matters as much as the number of hydrophones. Spaced too far apart, the array cannot tell one direction from another that happens to give the same phase pattern. A second full-strength beam appears: a **grating lobe**.

Grating lobes are avoided when

$$
\frac{d}{\lambda} \le \frac{1}{1 + |\sin\theta_0|}
$$

which is half a wavelength if the array must steer all the way to endfire, and up to one wavelength if it only looks broadside.

An array is therefore built for a **design frequency**. Below it, the hydrophones are closer than they need to be and the beam is wide. Above it, grating lobes appear.

:::pipeline
A processor working above the array’s design frequency does not have the beam pattern the nominal DI assumes. If a sensor definition carries a single DI value for all processors, the high-band processors are being flattered.
:::

# Beams in the prediction

## Vertical beams and D/E coverage

An array with vertical extent forms beams in elevation. Each has a D/E steer and a vertical beamwidth, and together they define which arrival angles the sensor can hear.

This is where unit 6 meets the array. Each eigenray arrives at its own D/E and is weighted by the vertical pattern:

- A sonar with a single wide vertical beam accepts every path, along with noise and reverberation from every vertical direction.
- A sonar with several narrow D/E beams can separate a duct path near horizontal from a bottom-bounce path arriving from 20° below, and it rejects surface and bottom reverberation on the horizontal beam.

Depression of the beam is a choice. Steering down favors bottom-bounce paths and puts more energy on the seabed. Steering horizontal favors ducts and direct paths.

:::operator
“Which D/E beam” is a search decision, like depth. The right answer is the beam that contains the path to the target and as little of the boundaries as possible.
:::

## Transmit beams

The source is an array too, and its pattern shapes what is sent.

A directional source concentrates its power. The level in the beam is higher than an omnidirectional source of the same power would give, by the transmit directivity index:

$$
SL = 171 + 10 \log_{10} P_{acoustic} + DI_T
$$

with acoustic power in watts and level in dB re 1 µPa at 1 m. One kilowatt radiated omnidirectionally is about 201 dB. With 20 dB of transmit directivity it is 221 dB in the beam.

The transmit pattern also decides what gets insonified. Sound not sent toward the bottom cannot return as bottom reverberation. Sound not sent in some direction finds no target there, whatever the receiver does.

:::pipeline
Source level is quoted on the axis of the transmit beam. Away from the axis the effective source level is lower by the pattern. Whether that reduction lives in the source level, in the loss field or in a separate term is a bookkeeping choice that must be made once.
:::

## Beams, bearings and the display

Beams are how measurements are organized, so they shape the data.

- Every measured quantity is **per beam**: measured beam noise, measured reverberation, contacts.
- A plan view in true bearing is built by mapping each beam to the bearings it covers, using the heading at the time.
- Adjacent beams overlap, usually near their half-power points, so the response between them dips by a decibel or two. This is **scalloping loss**.

A model works the other way. It computes on bearing radials chosen for the environment and has no beams until a sensor is specified. Putting model output and measured data on one display means resampling one onto the other’s grid.

:::pitfall
Beam number is not bearing. A table of measured noise indexed by beam number, drawn against true bearing without the heading applied, is rotated by the ship’s heading. It will look plausible. It will be wrong by exactly that angle.
:::

## Adaptive beamforming in brief

The beamformer described so far uses fixed weights. An **adaptive** beamformer chooses its weights from the data, placing nulls in the directions of strong interferers while keeping full response in the look direction.

Against a noise field dominated by a few loud ships, adaptive processing can gain many decibels over a conventional beamformer. Against smooth, even noise it gains nothing.

For prediction this has one practical consequence. A model with a fixed beam pattern cannot predict what an adaptive beamformer will achieve, because that depends on where the interferers are at the moment. Measured beam noise from an adaptive system already includes the benefit.

:::key
The more a sensor’s processing adapts to the moment, the more a measurement at its output is worth compared with a model of its input.
:::
